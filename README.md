<h3 align="left">🚀 Projeto em destaque</h3>

<table>
  <tr>
    <td width="100%">
      <h4><a href="https://github.com/joaovictorgcu/smart-job-apply">smart-job-apply</a> &nbsp;·&nbsp; <sub>Python · FastAPI · React · Playwright · IA</sub></h4>
      <p>
        Plataforma full-stack que assiste candidaturas no LinkedIn: busca vagas, pontua cada uma
        (0–100) contra o currículo usando IA, redige carta de apresentação e respostas de triagem,
        preenche o formulário — e <strong>para pra revisão humana antes de qualquer envio</strong>.
      </p>
      <ul>
        <li><strong>Full-stack de verdade:</strong> API em FastAPI (SQLAlchemy 2 async, Alembic), painel em React + Vite, atividade ao vivo via WebSocket.</li>
        <li><strong>Automação de navegador</strong> com Playwright + Chromium, empacotado em Docker.</li>
        <li><strong>Arquitetura em camadas:</strong> o engine de orquestração nunca toca no Playwright — fala só em dataclasses, o que deixa toda a lógica testável offline contra <em>fakes</em>, sem navegador nem conta.</li>
        <li><strong>Segurança:</strong> sessão criptografada em repouso (Fernet + HKDF-SHA256), JWT + bcrypt, e um design de "nenhum envio sem confirmação" imposto em múltiplas camadas.</li>
      </ul>
    </td>
  </tr>
